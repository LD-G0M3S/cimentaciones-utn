# cimentaciones-utn

Herramientas interactivas de cálculo para la cátedra de Cimentaciones - UTN FRGP (Universidad Tecnológica Nacional, Facultad Regional General Pacheco).

Aplicaciones web pensadas para hacer visible conceptos que en el pizarrón quedan en una fórmula: se modifican los datos y las verificaciones se recalculan en tiempo real, con los diagramas asociados.

## Herramientas disponibles

### Fundación con carga excéntrica

Zapata sometida a carga normal y momento, resuelta en paralelo por los dos criterios que conviven en la práctica argentina:

- **Verificación geotécnica (estado límite de servicio):** cargas de servicio, excentricidad, control de despegue, tensión máxima contra tensión admisible.
- **Diseño estructural (estado límite último):** cargas mayoradas, área efectiva según el criterio de Meyerhof, presión de diseño para el dimensionamiento del hormigón.

El objetivo didáctico es hacer explícito que la presión mayorada es un artificio de cálculo necesario para diseñar el hormigón, y no una presión que el suelo llegue a experimentar.

**Base normativa:** CIRSOC 101-2005, CIRSOC 201-2005 y conceptos de la norma EN 1997-1 (Eurocódigo 7).
